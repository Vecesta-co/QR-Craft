## 2. Asset provenance

### Block textures

All block textures are **original 16 × 16 procedural textures** generated at runtime by `src/lib/render/textures.ts`. They are produced from:

- colours defined in this repository's block registry;
- pattern algorithms written for this project;
- per-block seeds derived from the block id.

No Minecraft texture files, texture atlases, resource packs or extracted game assets are included, copied or recoloured.

### Geometry, sky, water and effects

The voxel world, terrain, buildings, landmarks, vegetation, builder figure, sky shader and sea plane are generated by code in this repository. No third-party models, HDR maps, skyboxes, sprites or particle textures are shipped.

### Fonts

The UI uses system font stacks only (Iowan Old Style / Palatino / Georgia, Segoe UI / system UI, Cascadia Mono / Consolas). No font files are redistributed.

### Icons

Icons come from `lucide-react`, which is licensed under **ISC**. The brand mark is an original inline SVG.

### Block identifiers

QR Craft uses namespaced block identifiers such as `minecraft:deepslate_tiles` as **factual interoperability names**. These strings identify block types in the Minecraft data model. Their use is not a claim that Mojang-authored code, textures or other assets are included, nor a claim of affiliation or endorsement.

The registry is validated against `minecraft-data` 1.21.4 in the test suite. That package is a **development-only** dependency; it is not part of the runtime bundle.

### User-provided QR images

Uploaded PNG/JPEG/WebP files are decoded **locally in the browser** to extract their text. The image itself is not uploaded to a server, stored in a database or included in exports. Only the decoded payload is used to build a new canonical matrix.

### Generated exports

GLB, PLY, STL and Sponge schematic files are generated from the user's own generated world. They contain no Mojang assets. You are responsible for the content you encode and for how you distribute the resulting files.
